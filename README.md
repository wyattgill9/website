# wyattgill.com

My personal site: a dragon pond, [projects](src/app/projects/page.tsx), and a [shelf](src/app/shelf/shelf.md) of what I'm reading and watching. The shelf's Film, Anime and Manga sections sync daily from Letterboxd and MyAnimeList (`MAL_CLIENT_ID`, see `.env.example`).

```sh
npm ci
npm run dev
```

Built on [Dao Ho's portfolio](https://github.com/Dao-Ho/portfolio); the pond renderer and the site's layout started as Dao's work.
